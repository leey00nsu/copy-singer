# Custom Rules

> ⚠️ 이 문서는 **사용자 정의 규칙**입니다.
> `npx lee-spec-kit update`의 영향을 받지 않습니다.
> **이 문서의 규칙은 다른 모든 agents 규칙보다 우선합니다.**

---

## 프로젝트 특화 규칙

- Next.js는 사용자가 명시적으로 요청하기 전까지 로컬 전용으로 유지한다.
- Modal 배포는 백엔드 변경 적용에 필요할 때만 수행하고 결과 endpoint를 변경하지 않는다.
- 실제 음원으로 테스트할 때 사용자가 제공한 파일만 사용하며 결과는 `outputs/`에 저장하고 Git에 포함하지 않는다.

---

## 추가 언어/코드 규칙

- 사용자 응답과 제품 문서는 한국어로 작성한다.
- 환경 변수 이름, API 경로, 코드 식별자는 영어를 유지한다.

---

## 커스텀 워크플로우

- 요구사항은 `docs/prd/vocal-loom-prd.md`에 안정적인 `PRD-*` ID로 먼저 기록한다.
- 구현 전 필요하면 idea를 만들고, 확정된 작업만 component feature로 승격한다.
- 웹 기능은 `web`, Modal/FastAPI/GPU 기능은 `modal-api` 컴포넌트에서 관리한다.
- 두 컴포넌트를 함께 변경하는 기능은 주 책임 컴포넌트에 feature를 두고 plan에 교차 변경 경로를 기록한다.

---

## 기타

- 비용이 발생하는 실제 GPU 검증은 필요한 최소 횟수와 합리적인 diffusion steps로 수행한다.
- 음성·음원 사용 권한과 24시간 보관 정책을 사용자-visible UI에서 유지한다.
