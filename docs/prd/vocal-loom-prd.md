# Vocal Loom PRD

- **상태**: Baseline
- **버전**: 0.1
- **작성일**: 2026-08-05
- **제품 범위**: 로컬 Next.js 웹 앱 + Modal 기반 SoulX-Singer SVC API

## 제품 개요

Vocal Loom은 사용자가 권한을 가진 레퍼런스 가창 음성과 변환 대상 노래를 입력하면, 대상의 멜로디·타이밍·표현을 유지하면서 레퍼런스 음색으로 변환된 WAV를 만드는 테스트용 워크벤치다.

## 목표

- 두 오디오와 변환 옵션을 한 화면에서 입력하고 결과를 확인한다.
- 긴 GPU 작업을 비동기 작업으로 처리해 브라우저 요청 시간 제한과 분리한다.
- Modal API 키를 브라우저에 노출하지 않는다.
- 월별 Modal 무료 크레딧 범위에서 실험 가능한 운영 구조를 유지한다.

## 제외 범위

- 다중 사용자 계정, 결제, 공개 서비스 운영
- 음성 소유권 자동 검증 및 저작권 라이선스 판정
- 영구 결과 보관 및 작업 이력 검색
- 실시간 스트리밍 변환

## 사용자 스토리

- **PRD-US-001**: 사용자는 레퍼런스 음성과 변환 대상 오디오를 선택하고 각각 미리 들을 수 있다.
- **PRD-US-002**: 사용자는 음정, 확산 단계, CFG, 시드 및 보컬 분리 옵션을 조정할 수 있다.
- **PRD-US-003**: 사용자는 변환 진행 상태와 실패 원인을 확인할 수 있다.
- **PRD-US-004**: 사용자는 완료된 결과를 재생하거나 WAV로 다운로드할 수 있다.

## 기능 요구사항

- **PRD-FR-001**: 웹 앱은 WAV, MP3, FLAC, M4A, OGG, AAC, WebM 오디오 입력을 받아야 한다.
- **PRD-FR-002**: 레퍼런스는 최대 30초를 사용하고 업로드 크기는 128MB 이하로 제한한다.
- **PRD-FR-003**: 타겟은 최대 5분을 사용하고 업로드 크기는 256MB 이하로 제한한다.
- **PRD-FR-004**: 변환 요청은 `queued → processing → succeeded | failed` 상태를 제공해야 한다.
- **PRD-FR-005**: 진행 중인 작업은 취소할 수 있고 완료 결과는 WAV로 제공해야 한다.
- **PRD-FR-006**: 보컬 분리, 자동 음정 이동, 반주 재믹스, 수동 pitch shift, diffusion steps, CFG, seed를 전달해야 한다.
- **PRD-FR-007**: Next.js 서버는 Modal API를 same-origin 경로로 프록시하고 인증 키를 서버 환경 변수로만 관리해야 한다.

## 비기능 요구사항

- **PRD-NFR-001 보안**: `MODAL_API_KEY`는 `NEXT_PUBLIC_*` 변수, 클라이언트 번들, 로그 또는 Git에 포함하지 않는다.
- **PRD-NFR-002 개인정보**: 입력과 결과는 24시간 후 정리하며 사용자가 명시적으로 삭제할 수 있어야 한다.
- **PRD-NFR-003 비용**: 기본 GPU는 L4, GPU 컨테이너 수는 1개로 유지하며 idle window를 짧게 유지한다.
- **PRD-NFR-004 안정성**: 대용량 multipart 업로드는 Next.js에서 버퍼링하지 않고 Modal로 스트리밍한다.
- **PRD-NFR-005 품질**: 변경 시 TypeScript 검사, ESLint, 프로덕션 빌드를 통과해야 한다.
- **PRD-NFR-006 책임 있는 사용**: 사용 권한이 있는 음성과 음악만 처리하도록 UI에 고지한다.

## 현재 검증 기준

- 레퍼런스 `vocal1.wav`와 183초 MP3 타겟으로 실제 Modal 변환이 완료된다.
- 생성된 결과가 183초 WAV로 다운로드되고 브라우저에서 재생된다.
- API health가 Modal 플랫폼 및 GPU 정보를 포함한 `200` 응답을 반환한다.

## 향후 후보

- 요청별 사용량 제한 및 비용 관측
- 악용 신고와 동의 증빙 흐름
- 작업 이력과 장기 보관 스토리지
